# Edit Markdown visually

Markdown files can open as a rich document in the web and desktop file preview.
Switch a file between source and Rich mode from its file header.
Edits autosave through the same save flow as source editing.

## What Rich mode covers

Rich mode supports CommonMark and GitHub Flavored Markdown: headings, emphasis, links, lists, task lists, tables, blockquotes, and code blocks.

- **Frontmatter:** YAML edits as a code block.
- **Workspace links:** file chips and navigation.
- **Task lists:** checkboxes stay interactive.
- **Fenced code:** app theme, font, and wrap.

## Try the showcase

Search for `docs/user/markdown-showcase.md` in T3 Code and switch it to Rich mode.
The [Rich Markdown showcase](./markdown-showcase.md) exercises the supported syntax in one document.

## Limits

- **MDX:** rendered preview only, JSX is unsafe.
- **Truncated preview:** cannot enter Rich mode.
- **Normalizing:** equivalent syntax may change.

Use Source mode when exact byte formatting matters.
