# Edit Markdown visually

Switch a Markdown file to **Rich mode** from its file header to edit it as a document.
Edits **autosave** like source edits.

Rich mode covers CommonMark and GitHub Flavored Markdown, YAML frontmatter, task-list checkboxes, and workspace links as file chips.
To try it, open the [Rich Markdown showcase](./markdown-showcase.md) in Rich mode.

## Limits

- **MDX** shows a rendered preview only
- **Truncated previews** cannot enter Rich mode
- **Equivalent syntax** may be rewritten

Use **Source mode** when exact formatting matters.
