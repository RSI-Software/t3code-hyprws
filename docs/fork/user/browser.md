# Browser bookmarks

Keep pages you use often one tab away in the desktop browser.

## Save a page

Select the star in the address field and choose a scope:

| Scope                | Appears in                            |
| -------------------- | ------------------------------------- |
| **Project bookmark** | the current project only              |
| **Global bookmark**  | every project on this T3 Code profile |

Open the star again to change the scope or remove it.

## Open a bookmark

Open a new browser tab; saved pages list first, project bookmarks on top.

Bookmarks **survive restarts** but **never sync** to other profiles or devices.
